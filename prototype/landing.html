素材上传与断点续传

分片续传单文件最大 2GB，断网断电按 offset 续传；zip/pdf/doc/xls/ppt 均可解析入库。

知识库自动内化

解析后自动切块、生成知识卡片，按用户隔离，后台排队分析，进度随时可查。

检索与知识问答

关键词检索命中片段与出处；问答结合知识库生成，资料不足明确说缺什么，不编造。

语音与图像生成

TTS 合成 wav（CosyVoice / Qwen3 双引擎），文生图出图，产物直接落盘可下载。

标准 MCP 接入

Streamable HTTP 暴露 13 个工具，手机号即可初始化会话，外部 agent 免改造直连。

工作台一体化

素材、知识库、创意灵感、运维监控同库同源，网页工作台与 MCP 工具共享同一份数据。
