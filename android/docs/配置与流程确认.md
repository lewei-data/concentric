## 1. 服务端配置（用户最终确认）

App 调用的是**同心圆 agent 服务**（`/conring/*`），不是同域名根路径的 FS/DB 服务。把内网 `192.168.31.208` 换成 `ai.boraydata.com` 并启用 HTTPS 即为正式端点：

| 服务 | 内网端点（应急，需 VPN） | 正式端点（App 使用） | serverInfo |
| --- | --- | --- | --- |
| mail | `http://192.168.31.208/conring/mail/ceo/mcp` | `https://ai.boraydata.com/conring/mail/ceo/mcp` | mail 1.0.0 |
| tts | `http://192.168.31.208/conring/tts/mcp` | `https://ai.boraydata.com/conring/tts/mcp` | tts 1.0.0 |
| **asr（App 调用）** | `http://192.168.31.208/conring/asr/mcp` | **`https://ai.boraydata.com/conring/asr/mcp`** | asr 1.0.0 |

> **易错点**：`https://ai.boraydata.com/mcp` 是另一套服务「SEFS Data MCP v2.1.0」（远程文件系统 / SQL / 媒体分析 / 向量检索 / 代码图谱，59 个工具），**没有 `voice_chat`**，且需要 Bearer Token（未带返回 401，申请页 `/token`）。本机 `~/.workbuddy/mcp.json` 里的 `sefs` 配置正是这一套，勿与 App 端点混淆。

## 4. 采用的流程（时序）

| 步 | 动作 | 数据 |
| --- | --- | --- |
| 1 | App 启动，申请 `RECORD_AUDIO`/`INTERNET`，载入配置 | 默认 `https://ai.boraydata.com/conring/asr/mcp` |
| 2 | 点击录音 → `AudioRecord` 采 16kHz/16bit/mono PCM | 最长 60 秒，约 1.9MB |
| 3 | 第二次点击 → 封装标准 WAV → base64 | 约 2.6MB 字符串（已验证云端可接受） |
| 4 | HTTPS POST `initialize` → 取 `mcp-session-id` → `notifications/initialized` → `tools/call` | `voice_chat{audio_base64, language, model, timeout_sec}` |
| 5 | 解析 `result.content`：text 块转可读文本（`question`/`answer` 优先）、audio 块解 base64 | 每块落盘一份到 `files/results/` |
| 6 | 结果区显示文字；自动播放服务端 WAV（缺失时系统 TTS 兜底） | 附件列表可点开；「查看文字」另存 txt 打开 |
| 7 | 会话失效或改配置 → 丢弃 session，下次重新握手 | 设置页改动后 `onResume` 立即生效 |

### 12.2 本地 / 远程分工

| 侧 | 职责 |
| --- | --- |
| 远程（同心圆 agent） | ASR 转写 → Hermes 按 `profile` 人设执行 → TTS 合成，返回 `answer` 文本 + WAV 音频（既有能力，未改动） |
| 本地（App） | 档案管理、形象渲染、`answer` 分句字幕、WAV PCM 包络解析、口型/表情/动作实时驱动、视频素材播放 |

选择「本地解析同一份 WAV 驱动渲染」而不是「服务端返回数字人视频」，因为服务端没有该能力，且同一份音源驱动天然音画同步、可离线重播、不增加带宽。

### 12.3 时序变化

```
录音 → voice_chat(profile=当前员工) → ResultParser 落盘 WAV + 提取 question/answer
     → showResult → ReportActivity 全屏汇报画面
         ├─ LipSync.fromWav(WAV) → 40ms/帧的 level + 口型时间轴
         ├─ MediaPlayer 播放 WAV；~30fps 按 getCurrentPosition() 查表
         ├─ DigitalHumanView 渲染嘴型 / 表情 / 呼吸·点头·摆头·眨眼·手势
         ├─ 答案按句读分句，按字数比例分配时间，逐句淡入字幕
         └─ 播完收势：致意表情 + 「汇报完毕」
```

设置页关闭「汇报画面」时退回原来的 `VoicePlayer` 纯语音播报，链路可逆。

### 12.5 待确认 / 后续

1. **真实的仿真人 mp4 未提供**：字段、解析、循环静音播放、失败回退均已实现，示例档案里 `videoIdle` / `videoTalk` 留空，放入素材即生效。
