本手册面向使用者（老板本人及代装机的同事），只讲「怎么用、出问题怎么查」，不涉及代码。对应 App：桌面名「同心圆」，版本基线 0.13.3 / b47；安装包在 `/mnt/sefs/conring/tmp/voice-mcp-v0.13.3-b47-release.apk`（每次构建自动镜像到这里）。

## 1. 安装与升级

1. 拷 APK 到手机（微信/QQ/数据线/局域网皆可），点击安装；首次会提示「允许安装未知来源应用」。
2. **升级直接覆盖安装即可，不必卸载**——0.13.3 起 debug 与 release 使用同一张证书，任意版本都能覆盖。若仍提示「签名不一致」，说明手机上装的是更早的旧包，卸载一次再装（只此一次）。
3. 首次启动授予：麦克风（按住说话/通话必需）、通知（保持监听、任务完成提醒）。拒绝麦克风的后果是按住说话直接提示无权限。
4. 系统要求：Android 8.0（API 26）及以上。

## 2. 首次登录

1. 打开 App 先到登录页。若系统能读到本机号码，会弹「是否使用本机号码登录」，确认后自动填好账号；双卡会列出两个号码让你选，也可以选「手动输入其他号码」。
2. 输入密码（就是工作台网页那套账号密码，`users.db` 手机号 + 密码，也兼容「登录凭据.md」里的账号）。**没有免密登录**，本机号码只用来填账号。
3. 登录成功后进入首页。登录态是 Cookie，过期后语音模式会提示「登录已过期，请重新登录」，重新登录即可。
4. 只有老板账号能用语音模式；其它账号会提示「当前账号不是老板，语音模式只对老板开放」。

## 3. 首页导览

| 位置 | 元素 | 作用 |
|---|---|---|
| 顶栏 | 标题 + 状态点 + 端点地址 | 看当前连的是哪个服务端点、网络/登录状态 |
| 顶栏右 | 通话图标 | 一键发起/挂断实时语音通话，接通后变红 |
| 员工卡 | 数字员工（仿真人/照片）+ 姓名职位 | 当前「汇报人」，点卡片进档案，可换人 |
| 中间大圆钮 | **按住说话** | 主入口，见第 4 节 |
| 通话条 | 通话中才出现：时长 + 电平 + 红色挂断 | 接通后大圆钮收起，只留这条 |
| 会话摘要 | 今天和汇报人的对话流水 | 点开成整页会话面板，可拖高度 |
| 快捷入口 | 当前进度 / 待办 / 设置 | 见第 6、7、9 节 |
| 结果区 | 文字结果 + 附件 | 附件可点开用系统应用查看 |

## 4. 按住说话（最常用）

1. **按住**大圆钮开始录音：按钮缩小一点，上方出现「松开发送 · 时长」，下面是实时电平条。
2. 说错了就**手指上滑**（会提示「松开取消」），再松手即丢弃这段录音。
3. **松手**后自动上传识别：约 1–5 秒，上方显示「正在识别…」。
4. **识别完成**会先给你看文字，三个按钮选一个：

   - **重录**：丢掉这次结果重新按住说；
   - **发语音**：把小秘书的回复也用语音播出来（会话里同时留文字）；
   - **发送文字**：只发文字，回复按默认播报。

5. 发送后显示「已发送，等小秘书回复 · 也可以接着说」——**不必等她说完**，可以继续按住说下一句；接话时上一句的回复仍会留在会话里。
6. 回复到了会自动播报。播报声音来自服务端合成（小秘书自己的音色），失败时才用手机自带 TTS。

小提示：按住不足 0.4 秒或太轻会被判为「没说话」，提示「按住多说一会再松手」；单次最长 60 秒，超时会自动收尾并照常识别。

## 5. 实时语音通话（对话感更强）

1. 点顶栏**通话图标**：开始拨号（有本地合成的「叮-叮-咚」拨号音），上方显示「正在接通…」。
2. 接通后首页收成一条通话条：时长、实时电平、红色挂断。此时**不用按住**，直接说话即可，系统自动断句。
3. 小秘书说话时你可以随时打断（开口即停播报，直接说你的）。
4. 点红色挂断结束通话；通话在后台也会继续（切到其它 App 不断），回落时首页通话图标保持红色。
5. 20 秒还没接通会自动取消并提示「连接超时，稍后再试（或直接用按住说话）」；点通话图标再点一次即可手动取消。

## 6. 数字员工档案

- 首页点员工卡 → 进入该员工档案：可播放服务端生成的自我介绍视频（画面+语音，同一份音频驱动口型）、查看职位/技能/常用语。
- 档案页有「试听汇报」：用该员工的专属音色合成一段真实语音再播放，不是手机朗读。
- 点「发起实时通话」可直接和这位员工通话；在档案页里换人后，首页的汇报人同步变化。
- 视频只在**本次运行首次**打开该员工时自动播放，之后停在首帧等你点播放（省流量、防打扰）。

## 7. 当前进度（小秘书简报）

首页「当前进度」→ 展示小秘书整理的简报：一句话结论、进展、风险与异常、客户与交付。数据来自服务端 `boss_briefing`，进页面先显示上次缓存再后台刷新，所以**打开即有内容**，不用等转圈。

## 8. 待办审批

首页「待办」→ 逐条列出「需要你拍板」的事项（急件置顶，带 A/B 选项与建议）。

- 点「通过」或「不通过」后，App 把决定合成语音发给小秘书由她真正执行，本机只记「已提交」；
- 最终状态以服务端下一轮简报为准，所以提交后看到的状态可能短暂仍是旧的，属正常。

## 9. 历史与会话

- **历史**（首页结果区下方 / 员工页入口）：所有语音指令结果、服务端推送、CEO 新邮件都在这里，一条记录一行，可看详情、重播音频、播放视频、打开附件、重新汇报。
- **会话面板**：首页会话摘要点开，是与当前汇报人按「人 + 天」的对话流水。最新消息在最下面，往上翻到顶自动加载前一天；顶部把手可上下拖动改高度。

## 10. 设置

| 项 | 说明 |
|---|---|
| 服务端点 | 默认 `https://ai.boraydata.com/conring/asr/mcp`。**不要填成 `https://ai.boraydata.com/mcp`**（那是另一套 SEFS Data MCP，没有 voice_chat） |
| 工具名 / 参数名 / 超时 | 一般不用改，联调时才动 |
| 保持监听 | 打开后常驻通知「同心圆 · 保持监听」，后台接收任务完成/推送/新邮件并播报；开会或省电时可关 |
| 演示模式 | 不依赖服务端，用内置素材演示界面 |
| 连通性测试 | 一键测端点可达性与工具发现，排障第一步 |

## 11. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 装不上 / 提示「应用未安装」「签名不一致」 | 手机上是更早的旧证书包，卸载一次再装；此后所有版本同证书，不再需要卸载 |
| 按住说话提示「语音需要麦克风权限」 | 系统设置里给「同心圆」开麦克风权限（设置→应用→同心圆→权限） |
| 提示「登录已过期」或语音模式报 forbidden | 回到登录页重新登录；确认账号是老板账号 |
| 识别总失败 / 一直「正在识别…」 | 先看顶栏端点是否正确，再在设置里做连通性测试；公司网络若拦截请在设置里切内网端点 |
| 按了没反应、一直显示「正在接通…」 | 20 秒会自动取消；也可以再点一次通话图标手动取消，改用按住说话 |
| 没有声音 | 检查媒体音量与是否静音；档案页「语音控制」全局开关被关时视频会静音；系统 TTS 未安装时可先看文字 |
| 后台收不到任务完成提醒 | 打开「保持监听」并允许通知；国产系统还需在电池/自启动设置里允许后台运行 |
| 手机发烫 / 耗电快 | 关掉「保持监听」；避免长时间开实时通话；App 不做常驻轮询以外的后台动作 |
| 会话面板里少了某句 | 消息以服务端 `chat_messages` 为准，本机只是镜像；换设备不迁移本机会话 |

## 12. 版本与取包

- 出包只有一条命令：`cd android && ./gradlew collectApks`。
- 产物同时落两处：`android/dist/voice-mcp-v<版本>-b<号>-release.apk` 与 `/mnt/sefs/conring/tmp/`（同名）。
- 当前基线 0.13.3 / b47，签名证书固定为 `signing/conring-release.jks`（指纹 `c8db44ed…85bae`），每次构建都会校验，不会悄悄换证书。
