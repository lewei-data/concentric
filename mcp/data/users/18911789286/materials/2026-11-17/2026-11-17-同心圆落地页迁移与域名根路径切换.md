# 同心圆知识管理体系：首页迁移与域名根路径切换（2026-11-17）

## 背景与目标

把 ai.boraydata.com 域名下原「SEFS Data MCP · 数字分身」首页迁移进 OPC Workbench，
更名为「同心圆知识管理体系」，并检查配套功能、适配 workbench 的 opc-mcp 服务。
最终域名根路径 `https://ai.boraydata.com/` 直接下发新落地页。

## 一、落地页迁移（workbench 侧）

- 新增 `prototype/landing.html`：原首页视觉整体迁移（深色渐变、网格背景、shimmer 主词、动效与 reduced-motion 降级全部保留）。
  - 品牌与标题改为「同心圆知识管理体系」；主视觉词「数字分身 / Digital Twin」改为「同心圆 / Concentric Knowledge System」；logo 改为三环同心圆。
  - 链接适配 workbench：申请 Token → `/login`，健康状态 → `/api/health`，进入工作台 → `/app`；页脚 MCP 端点由 JS 取 `window.location.origin + "/mcp"`，在域名根与 `/workbench/` 两种入口下都指向公网 MCP 端点。
  - 功能卡片从原 SEFS 的 5 项（远程文件系统 / SQL / 媒体分析 / 向量检索 / 代码图谱）改写为 opc-mcp 实际具备的 6 项：素材上传与断点续传（单文件 2GB）、知识库自动内化、检索与知识问答（kb_search / ask，资料不足不编造）、语音与图像生成（CosyVoice / Qwen3 TTS + 文生图）、标准 MCP 接入（Streamable HTTP 13 工具，手机号初始化 session_token）、工作台一体化（同库同源）。
- `prototype/server.py` 两处改动：
  - 根路径 `/` 由「302 → /app」改为公开下发 `landing.html`；`OPC_HOME_LEGACY=1` 回退旧版控制台的逻辑保留。
  - `/api/health` 从需登录区挪到公开区（仅返回版本/引擎/时间，无敏感数据），供落地页健康状态按钮匿名访问。
- `README.md` 页面与接口表同步更新 `/` 说明。

## 二、域名根路径切换（208 nginx 网关）

- 新增 snippet `/etc/nginx/snippets/workbench-root.conf`：
  - `location /` → `http://192.168.21.206:8848/`。根路径下 workbench 的绝对路径（/login、/app、/api/*）直接命中，无需 sub_filter 前缀改写（`/workbench/` 路由及其 sub_filter 不受影响）。
  - `location = /token` → 127.0.0.1:8765，保留 sefs-mcp 的 token 申请页。
  - `location /conring/` → 127.0.0.1:8765，保留未匹配 `/conring/*` 的 `realm="sefs-mcp"` 401 兜底语义。
  - `location = /api/events` 单独关 buffering，保 SSE 长连接。
- `proxy_8001.conf`（443，certbot 证书行原样保留）与 `sefs-mcp.conf`（80 default_server）的 `location /` 替换为 include 新 snippet。
- 改前备份：`*.bak-root-<时间戳>`；`nginx -t` 通过后 `systemctl reload nginx`（不断 SSE）。
